Announcing Amazon Textract Insights: Verifiable generative AI for documents

Amazon Textract’s new feature, Textract Insights, is now generally available. It lets users describe the needed fields in natural language, then returns structured results after ingesting a single document or a mixed document batch, with confidence scores and page-level grounding for each value, without requiring model training.

Test / Enterprise AI

Cut self-hosted LLM cost and latency with the distributed KV caching agent skill

AWS introduced a distributed KV caching agent skill for self-hosted LLMs that can use Amazon ElastiCache to reduce repeated context computation, claiming it can cut inference costs by up to 40% and reduce first-token latency by up to 80%.
